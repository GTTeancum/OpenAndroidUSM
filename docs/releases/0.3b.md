# OpenAndroidUSM 0.3b

This is a **very early preview** of the source-level C++ reconstruction of
*Ultimate Spider-Man: Total Mayhem* for Android/Xperia Play. It is not a
finished game or a claim of full parity with the original.

**Development is temporarily paused.** This release preserves the current
work for others to inspect, build, and report issues against. There is no
announced date for development to resume.

## Current state

- Opening cinematics, authored scene transforms, baked lighting, character
  animation, UI, and audio have been reconstructed.
- Substantial portions of first-level gameplay are implemented. Combat work
  includes player combos, targeting, web attacks, hit reactions, health and
  damage, enemy attacks, and accompanying effects and audio.
- Reverse-engineered combat work most recently covered Room 9's heavy enemy,
  including rockets, Spider-Sense evasion, melee hit timing, and player damage
  feedback. That checkpoint passed the four CTest targets and its focused
  15-assertion heavy-melee autoplay scenario.
- Deterministic autoplay and detailed state/event logging are available to
  help reproduce problems. Passing these checks does not establish complete
  parity with the original game.

## Known limitations

Combat and effects are still incomplete. Sandman's original task sequence,
sand-hand attack, and related presentation need further reconstruction. The
latest source changes begin restoring his health phases and authored combo
successors; **those changes have not been built or tested**, so the earlier
test results do not validate this release's complete source tree.

Progression and later-game systems remain incomplete or insufficiently
verified. Hostage rescue, specific anchored swing sequences, and the bus
quick-time prompt are among the reported follow-up areas. Expect bugs,
missing features, visual/audio differences, and possible progression blockers.

## Downloads and setup

This is a source checkpoint. GitHub provides the tagged source archives;
no compiled executable or original game assets are attached. Follow the
[README](https://github.com/GTTeancum/OpenAndroidUSM/blob/0.3b/README.md) to
import your own legally obtained game data and build on Windows. Original
game binaries, assets, and reverse-engineering databases are not distributed.

## Please report issues

The repository is public and
[GitHub Issues](https://github.com/GTTeancum/OpenAndroidUSM/issues) is open.
Please report bugs and differences from the original, including version
`0.3b`, the level or encounter, reproduction steps, and logs or screenshots
when available. Original-game comparisons are particularly useful for this
reverse-engineering project. Reports are welcome while development is paused;
responses and fixes may be delayed.
